# ambient-desktop

The Linux notes window. The title is Aerodash. Iced draws the controls. There is no webview. The shell is notes and conversations. A note is one editor. Markdown is styled as it is typed: headings, bold, italic, bold-italic, strike, highlight, code, quotes, lists, tasks, tables, links, images, and note links. Opening `**` starts bold and the closing pair ends it. That word leaves the marks immediately. The run the caret is in, or the link it is in, shows whole with its marks, and so does one the caret was moved to just after. An unclosed mark continues onto the next line until a blank line. The icon at the top right of a note turns on focus, which is for writing with nothing else in view: both panels are away, the title is small at the top right with a button beside it that brings the formatting bar in, the tags are away, and both side panels ease away. Leaving focus brings them back the same way. The panels stay in the row at a width of zero so the page keeps its place in the widget tree and keeps the caret. Focus is only for the wide layout and a note being written. It does not change what the panels remember, so leaving puts everything back. A later version will spotlight the paragraph being written. The writing sits in the middle column, centered, and wraps at a readable measure. Closing the list or the group panel gives that space to the middle. The writing does not run under either panel. A heading on the page is a real size, smaller than the note title, and the same color as the text. A strike is a line through the letters. The marks stay in the text, and that text is what is saved. Enter in the title moves to the writing. Ctrl or Cmd with a full stop is focus. Ctrl or Cmd with Shift and D adds the word at the caret to a personal dictionary, a plain file named `dictionary` in the notebook folder that stays on this computer and is read by the spellcheck. Erasing the notebook erases it and clears the words in memory, so they cannot be written into the next notebook. The Keys card in settings lists the keys. Back up, in settings, copies the notebook folder to a typed place, by hand. The copy holds the key file, so the card warns when the key file is not wrapped. It leaves out `export/`, which is readable Markdown, and the search index. It is made in a `.partial` folder and renamed when whole, never overwrites an earlier copy, refuses a place inside the notebook before making anything, and holds the notes and chat locks while it runs. Do not add a folder-picker crate for it. Do not put anything readable into a copy that the notebook does not already keep sealed. The task field takes the cursor when the Tasks tab opens and keeps it after a task is added. Enter in a list, a task, or a quote inserts the next marker, and Enter on an empty one ends the list, or steps a nested one out a level. Tab nests the list items under the caret or a selection and Shift+Tab brings them out. Ctrl or Cmd with B, I, K, or E is bold, italic, link, or code, and with Shift and X or H is strike or highlight. A new task is unchecked. Backspace on an empty item leaves the list. The open note does not keep a second task editor. A task is the toolbar button, or a checkbox line, and the Tasks screen is the view across notes. There are no buttons under the note on a wide window. New note is at the bottom of the left list. Delete shows on a row when the pointer is over it, and asks first. Send to a chat and Delete are in the note's settings, the panel the gear at the top of the right panel switches to, and which also shows the home device. The gear switches back to links and backlinks, the default. A narrow window keeps the round buttons. Selecting words shows Send in the pill. It sends only those words, quoted, with the note's title, the lines, and the writing device, and cites the note. The Tasks note is not in the notes list. The Tasks tab opens it in a card. The tag field offers tags used in other notes as you type, those that start with the text first. A wheel notch moves a page step, as GTK does, not a fixed 60 pixels, and a touchpad is left as the system sends it. A key the editor did not take, while the page is up, is typed into the page from the window listener, so fast typing keeps every letter. Delete still asks, then writes a snapshot whose body is only the delete marker, and the list hides that note. A tag is a chip under the title, stored on a hidden line at the end of the note, and never read from a `#` in the writing. The left list files notes by those chips. A `#` in the writing is ordinary text. A pause saves the open note on this computer even when the relay is off. That write runs off the typing thread and does not reload the editor. Scrollbars are not drawn. A faint thin thumb shows for under a second after the pane under the pointer scrolls, and a clear one while the pointer is on the bar, so it can still be dragged. A format row lives in the note column, above the editor, when the window is wide, and at the bottom when the window is narrower than 720. It does not sit over the list. The buttons are grouped as Word, Line, and Insert, and each one has a hover label. A word mark (bold, italic, strike, highlight, code) wraps the selection, or the word under the caret, and toggles off if that word is already wrapped. A line mark (heading, list, task, quote) toggles the lines the caret touches. An insert (link, note link, image, table, rule, callout, code block) drops that block. After a drag, a range that is more than a caret shows a pill above those letters: bold, italic, strike, highlight, link, copy, cut, and paste. Escape clears the range. The line marks and the block inserts stay on the bar. A note with two or more note links is a group. The note's name is the group's name. A first line `Kind: issues` names the pieces, and is optional. The panel on the right lists those pieces, with each word count and the total, and the same list stays open on a piece. Notes that link here are listed under that. The count and that list wait out a short pause, so a keystroke only moves the caret and the letters. A note link stores the note's id and shows its title. An older link that is only a title still opens. Typing `[[` offers notes. A link with no note is drawn as unresolved. Command-click opens it. A plain click still places the caret. A missing name creates a note with that title. Read draws the pieces in that order, with a line between them, and does not write a combined note. The left list shows a group and the notes that belong to no group. A group's pieces sit under it. Search still finds a piece. The marks stay in the text. That narrow layout is also the list-then-page layout, so the window can sit beside another program. Chat messages are bubbles, yours on the right, in advisory-time order with the latest at the bottom. A file added in chat is copied into the notebook and cited from the message. The citation can sync. The bytes cannot. A video opens with the system. It is not played in the window. The file chip uses the bubble's text color. A globe at the right of the toolbar is the sync status: gray when nothing is connected, green when a relay is up and caught up, red when a relay is up and something is unsent. On a narrow window the globe is on the bottom bar. A checkmark beside it means the open note is saved on this computer. Advanced, behind the globe, is where a pinned relay or a backup is typed. The default is this computer. A gear opens settings. A sun or moon sets an explicit light or dark. Settings can also follow the system. Those choices, your name, and what you call someone are local files, not records. The contact card still has no name. Clicking the globe opens a popover, with the detail and the relay switch. The first screen is the word Aerodash, one letter at a time, over the two lines, for at least three seconds and until the folder is open. A new folder asks for a device name, a local personal name, and a color. An existing key skips that. The relay starts when the folder opens. The caret's thread paints and takes keys. Two background threads touch the folder, and a third only checks spelling. It never takes a lock. Notes and conversations use different locks. A full sync takes the notes lock first, then the chat lock, so a save cannot land in the middle of a sync. While a conversation is on screen, one thread pulls that mailbox a few times a second and appends new lines. A just-sent line is written locally and pushed immediately. The other thread builds the group list, the word counts, and the notes that link here, and it runs the slower full sync of notes and devices. A note search does not block a chat pull. The full sync leaves the open conversation to the faster pull. The group list is ready when the folder opens, before a note is clicked. A click reads the projection already in memory. The window keeps what it drew until a result arrives. A short pause writes the open note without moving the cursor. That pause is one wake, not a timer that redraws the window. Invite is a screen. Devices, recovery, people, and erasing the folder are settings. A device list can revoke a key from the root folder. The note list shows which device wrote a note. The page does not. The writer is in the note's settings. An unsaved note stays when you leave it. List rows are not the same control as Save, Send, or New note. After a pause, a misspelled word is underlined and a mark that is still open is one quiet line. The word list and where it came from are in `dict/`. Add a missing word to `dict/words-extra.txt`, not to the generated `dict/words.txt`. Opening a note checks that at once. Search shows a title match at once. The matching line under a note, and a conversation when a chat line matches, wait a moment and only the latest query runs. Conversation text is reread only when a log changes. A note link can name one version, written `[[id@version|title]]`. An older version is one event from an index built when the log was loaded. It opens read-only and is not saved over the current note. A task line and a chat line can cite a note. The citation is the note id. It is not a grant.

It calls [`Notebook`](../ambient-cli/src/session.rs) and the sync helpers in `ambient-cli`. The folder is the same one the CLI uses.

## Invariants

- Do not put protocol rules in this crate. Sealing, event encoding, and the relay JSON stay in the crates that already own them.
- The only network is the loopback relay that client starts or dials. Cleartext on `127.0.0.1` is not a public deployment. The window must say so.
- Do not claim the key file is the OS keystore, or that a paired device holds the root.
- This is the Linux app. Do not turn it into the Mac or Windows shell.

## Dependencies

May depend on: `ambient-cli`. The window is a client, not a protocol crate, so it is excluded from `just wasm-check`.

## Test

Editor decisions are tested in `ambient-cli` (`Draft`). Sync and pairing are tested there too. This crate is the window.

```
cargo run -p ambient-desktop -- path/to/folder
```

With no path it uses `./notebook`.
